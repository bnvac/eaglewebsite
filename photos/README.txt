Drop each stop's cover photo in this folder using the matching file name:

  photos/church.jpg      Church of Christ
  photos/partridge.jpg   John Partridge House
  photos/tavern.jpg      Richardson's Tavern
  photos/cemetery.jpg    Prospect Hill Cemetery
  photos/rockville.jpg   Rockville Chapel
  photos/station.jpg     Train Station
  photos/ellice.jpg      Ellice School
  photos/oakgrove.jpg    Oak Grove Farm
  photos/southend.jpg    South End Pond
  photos/niagara.jpg     Niagara Engine House No. 2

That single image is used in two places automatically:
  1. the cover photo (first slot) of the page's Photo Gallery, and
  2. the cover image on that stop's card on the homepage.

Until a file is added, both spots show a "Photo coming soon" placeholder.
A landscape image around 1200x800px (4:3) looks best. JPG is expected; if
you use PNG instead, change the .jpg extensions in the HTML to .png.
